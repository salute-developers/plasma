# GroupIconButton

## Использование
Компонент `GroupIconButton` — это обертка для IconButton. Принимает в себя группу кнопок-иконок.

```tsx live
import React from 'react';
import { GroupIconButton, IconButton } from '@salutejs/{{ package }}';
import { IconClose } from '@salutejs/plasma-icons';

export function App() {
    return (
        <GroupIconButton>
            {Array(5)
                .fill(true)
                .map((_, i) => (
                    <IconButton key={i}>
                        <IconClose color="inherit" size="s" />
                    </IconButton>
                ))}
        </GroupIconButton>
    );
}
```

## Примеры

### Размер и вид группы кнопок
Размер и вид группы задаются свойствами `size` и `view`.
С помощью свойства `isCommonButtonStyles` можно отключить переопределение стилей для всех кнопок внутри группы.
Тогда каждая кнопка будет иметь настраиваемый размер и вид.

```tsx live
import React from 'react';
import { GroupIconButton, IconButton } from '@salutejs/{{ package }}';
import { IconClose } from '@salutejs/plasma-icons';

export function App() {
    return (
        <div>
            <GroupIconButton size="s" view="secondary">
                {Array(5)
                    .fill(true)
                    .map((_, i) => (
                        <IconButton key={i}>
                            <IconClose color="inherit" size="s" />
                        </IconButton>
                    ))}
            </GroupIconButton>

            <GroupIconButton isCommonButtonStyles={false}>
                <IconButton size="m" view="default">
                    <IconClose color="inherit" size="s" />
                </IconButton>
                <IconButton size="s" view="accent">
                    <IconClose color="inherit" size="s" />
                </IconButton>
                <IconButton size="xs" view="secondary">
                    <IconClose color="inherit" size="s" />
                </IconButton>
            </GroupIconButton>
        </div>
    );
}
```

### Ориентация группы и отступы между кнопками

Группа может располагаться вертикально или горизонтально и иметь три вида отступов.
Для `shape="default"` и `shape="pilled"` значение `gap="dense"` равно 4px. Для `shape="segmented"` — 2px.

```tsx live
import React from 'react';
import { GroupIconButton, IconButton } from '@salutejs/{{ package }}';
import { IconClose } from '@salutejs/plasma-icons';

export function App() {
    return (
        <div>
            <GroupIconButton size="xs" orientation="vertical" gap="none">
                {Array(5)
                    .fill(true)
                    .map((_, i) => (
                        <IconButton key={i}>
                            <IconClose color="inherit" size="xs" />
                        </IconButton>
                    ))}
            </GroupIconButton>

            <GroupIconButton size="xs" orientation="horizontal" gap="wide">
                {Array(4)
                    .fill(true)
                    .map((_, i) => (
                        <IconButton key={i}>
                            <IconClose color="inherit" size="xs" />
                        </IconButton>
                    ))}
            </GroupIconButton>
        </div>
    );
}
```

### Границы кнопки
Границы кнопки задаются свойством `shape`: `segmented`, `default` и `pilled`.

```tsx live
import React from 'react';
import { GroupIconButton, IconButton } from '@salutejs/{{ package }}';
import { IconClose } from '@salutejs/plasma-icons';

export function App() {
    return (
        <div>
            <GroupIconButton size="xs" shape="segmented">
                {Array(3)
                    .fill(true)
                    .map((_, i) => (
                        <IconButton key={i}>
                            <IconClose color="inherit" size="xs" />
                        </IconButton>
                    ))}
            </GroupIconButton>

            <GroupIconButton size="xs" shape="default">
                {Array(3)
                    .fill(true)
                    .map((_, i) => (
                        <IconButton key={i}>
                            <IconClose color="inherit" size="xs" />
                        </IconButton>
                    ))}
            </GroupIconButton>

            <GroupIconButton size="xs" shape="pilled">
                {Array(3)
                    .fill(true)
                    .map((_, i) => (
                        <IconButton key={i}>
                            <IconClose color="inherit" size="xs" />
                        </IconButton>
                    ))}
            </GroupIconButton>
        </div>
    );
}
```
