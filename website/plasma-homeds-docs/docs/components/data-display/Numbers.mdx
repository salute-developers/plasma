# Numbers

<Description name="Numbers" />

Шрифт `SBLCD` входит в поставку компонента и подключается автоматически.
Семейство можно переопределить токеном `numbersTokens.fontFamily`.

Компонент отображает числовой `value`, выделяя дробную часть уменьшенным кеглем.
Единица измерения `unit` необязательна: поддерживаются `degree` (°) и `percent` (%).
`NaN` и бесконечные значения не отображаются.

```tsx live
import React from 'react';
import { Numbers } from '@salutejs/plasma-homeds';

export function App() {
    return (
        <div style={{padding: '2rem', background: 'var(--inverse-background-primary)' }}>
            <Numbers value={-28.8} unit="degree" size="m" />
        </div>
    );
}
```

## Символ перед числом

Проп `hasSymbolBefore` добавляет перед числом тильду.

```tsx live
import React from 'react';
import { Numbers } from '@salutejs/plasma-homeds';

export function App() {
    return (
        <div style={{ display: 'flex', flexDirection: 'column', gap: '1rem', padding: '2rem', background: 'var(--inverse-background-primary)' }}>
            <Numbers value={22} unit="degree" size="m" hasSymbolBefore />
            <Numbers value={-3.5} unit="degree" size="m" hasSymbolBefore />
        </div>
    );
}
```
