# List
Компонент списка

<PropsTable name="List" />

Компонент представляет собой список состоящий из `ListItem`.

ListItem представляет собой простой компонент с текстом, левым и правым слотами.



### Типы ListItem
<PropsTable name="ListItem" />

## Примеры

### Базовое использование
```tsx live
import React from 'react';
import { List, ListItem } from '@salutejs/plasma-homeds';
import { IconChevronRight } from '@salutejs/plasma-icons';

export function App() {
    return (
        <div>
            <List view="default" size="m" variant="normal">
                <ListItem contentRight={<IconChevronRight color="inherit" size="xs" />}>Test Item 1</ListItem>
                <ListItem contentRight={<IconChevronRight color="inherit" size="xs" />}>Test Item 2</ListItem>
                <ListItem disabled contentRight={<IconChevronRight color="inherit" size="xs" />}>
                    Test Item 3
                </ListItem>
                <ListItem contentRight={<IconChevronRight color="inherit" size="xs" />}>Test Item 4</ListItem>
            </List>
        </div>
    );
}
```

### Управление внешним видом

Внешний вид списка зависит от свойств `appearance`, `size`, `variant`, `hasBackground`, `hasItemBackground`.
Разделители между элементами можно включить свойством `hasDivider`.

<Tabs>
    <TabItem value="appearance" label="appearance" default>
        Свойство `appearance` переключает вид списка: `default` — обычный список, `numbered` — нумерованный.

        В `numbered` меняются только отступы и типографика. 
        Номер можно передать в `contentLeft` компонентом `Counter`.

        Для нумерованного списка дизайном не предусмотрены `variant`, `hasBackground`, `hasItemBackground` и `hasDivider`.

        ```tsx live
        import React from 'react';
        import { Counter, List, ListItem } from '@salutejs/plasma-homeds';
        import { IconChevronRight } from '@salutejs/plasma-icons';

        export function App() {
            const items = ['Откройте настройки устройства', 'Выберите раздел «Аккаунты»', 'Подтвердите вход кодом из СМС'];

            return (
                <div style={{ display: 'flex', flexDirection: 'column', gap: '2rem' }}>
                    <div>
                        <List appearance="default" size="m">
                            {items.map((item, index) => (
                                <ListItem key={index} contentRight={<IconChevronRight color="inherit" size="xs" />}>
                                    {item}
                                </ListItem>
                            ))}
                        </List>
                    </div>

                    <div>
                        <List appearance="numbered" size="m">
                            {items.map((item, index) => (
                                <ListItem
                                    key={index}
                                    contentLeft={<Counter size="s" view="secondary" count={index + 1} />}
                                >
                                    {item}
                                </ListItem>
                            ))}
                        </List>
                    </div>
                </div>
            );
        }
        ```
    </TabItem>
    <TabItem value="size" label="size">
        Размер списка задается свойством `size` (s, m).

        ```tsx live
        import React from 'react';
        import { List, ListItem } from '@salutejs/plasma-homeds';
        import { IconChevronRight } from '@salutejs/plasma-icons';

        export function App() {
            return (
                <div style={{ display: 'flex', flexDirection: 'column', gap: '1rem' }}>
                    <List size="s" variant="normal">
                        <ListItem contentRight={<IconChevronRight color="inherit" size="xs" />}>Size s</ListItem>
                        <ListItem contentRight={<IconChevronRight color="inherit" size="xs" />}>Size s</ListItem>
                    </List>

                    <List size="m" variant="normal">
                        <ListItem contentRight={<IconChevronRight color="inherit" size="xs" />}>Size m</ListItem>
                        <ListItem contentRight={<IconChevronRight color="inherit" size="xs" />}>Size m</ListItem>
                    </List>
                </div>
            );
        }
        ```
    </TabItem>
    <TabItem value="variant" label="variant">
        Свойство `variant` задает плотность списка: `normal` — обычная, `tight` — уменьшенные вертикальные отступы у элементов.

        ```tsx live
        import React from 'react';
        import { List, ListItem } from '@salutejs/plasma-homeds';
        import { IconChevronRight } from '@salutejs/plasma-icons';

        export function App() {
            return (
                <div style={{ display: 'flex', flexDirection: 'column', gap: '2rem' }}>
                    <div>
                        <List size="m" variant="normal" hasItemBackground>
                            <ListItem contentRight={<IconChevronRight color="inherit" size="xs" />}>Test Item 1</ListItem>
                            <ListItem contentRight={<IconChevronRight color="inherit" size="xs" />}>Test Item 2</ListItem>
                        </List>
                    </div>

                    <div>
                        <List size="m" variant="tight" hasItemBackground>
                            <ListItem contentRight={<IconChevronRight color="inherit" size="xs" />}>Test Item 1</ListItem>
                            <ListItem contentRight={<IconChevronRight color="inherit" size="xs" />}>Test Item 2</ListItem>
                        </List>
                    </div>
                </div>
            );
        }
        ```
    </TabItem>
    <TabItem value="hasBackground" label="hasBackground">
        Свойство `hasBackground` добавляет фон контейнеру списка и визуально объединяет элементы в одну группу.

        Свойство `hasDivider` добавляет разделители между элементами.

        ```tsx live
        import React from 'react';
        import { List, ListItem } from '@salutejs/plasma-homeds';
        import { IconChevronRight } from '@salutejs/plasma-icons';

        export function App() {
            return (
                <List hasBackground hasDivider>
                    <ListItem contentRight={<IconChevronRight color="inherit" size="xs" />}>Test Item 1</ListItem>
                    <ListItem contentRight={<IconChevronRight color="inherit" size="xs" />}>Test Item 2</ListItem>
                    <ListItem disabled contentRight={<IconChevronRight color="inherit" size="xs" />}>
                        Test Item 3
                    </ListItem>
                    <ListItem contentRight={<IconChevronRight color="inherit" size="xs" />}>Test Item 4</ListItem>
                </List>
            );
        }
        ```
    </TabItem>
    <TabItem value="hasItemBackground" label="hasItemBackground">
        Свойство `hasItemBackground` добавляет фон каждому элементу списка.

        ```tsx live
        import React from 'react';
        import { List, ListItem } from '@salutejs/plasma-homeds';
        import { IconChevronRight, IconPlasma } from '@salutejs/plasma-icons';

            return (
                <List hasItemBackground>
                    <ListItem
                        contentLeft={<IconPlasma color="inherit" size="s" />}
                        contentRight={<IconChevronRight color="inherit" size="xs" />}
                    >
                        Test Item 1
                    </ListItem>
                    <ListItem contentRight={<IconChevronRight color="inherit" size="xs" />}>Test Item 2</ListItem>
                    <ListItem disabled contentRight={<IconChevronRight color="inherit" size="xs" />}>
                        Test Item 3
                    </ListItem>
                    <ListItem contentRight={<IconChevronRight color="inherit" size="xs" />}>Test Item 4</ListItem>
                </List>
            );
        }
        ```
