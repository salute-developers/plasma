# Pagination

Pagination может отображаться в разных размерах и может содержать select с выбором количества элементов на странице
и быстрый выбор страницы.

## Pagination
<Description name="Pagination" />

## Использование
Компонент `Pagination` должен содержать параметр slots. Он обозначает количество кнопок в Pagination.

Количество страниц рассчитывается как `Math.ceil(count / perPage)`, если значение `perPage` задано; иначе оно равно `count`.

:::note
Свойство `hasPerPage` управляет только отображением селекта количества элементов на странице.
Переданный `perPage` учитывается и при `hasPerPage={false}`: например, `count={2000}` и `perPage={20}` дают `100` страниц.
:::

```tsx live
import React from 'react';
import { Pagination } from '@salutejs/plasma-homeds';

export function App() {
    return (
        <div style={{display: "flex", "flex-direction": "column"}}>
            <div>
                <Pagination size="m" slots={7} count={200} />
            </div>
            <div>
                <Pagination size="m" slots={9} count={200} hasPerPage={true} perPage={20} />
            </div>
            <div>
                <Pagination size="m" slots={9} count={200} hasPerPage={true} />
            </div>
            <div>
                <Pagination size="m" slots={9} count={200} hasPerPage={false} />
            </div>
        </div>
    );
}
```

## Примеры

### Размер Pagination
Размер Pagination задается с помощью свойства `size`.
Возможные значения свойства: `"m"`

```tsx live
import React from 'react';
import { Pagination } from '@salutejs/plasma-homeds';

export function App() {
    return (
        <div style={{display: "flex", "flex-direction": "column"}}>
            <Pagination size="m" slots={9} count={200} hasPerPage={true} />
        </div>
    );
}
```

### Вид Pagination
Вид Pagination задается с помощью свойства `view`. Возможные значения свойства `view`:
+ `"clear"` – чистая;

```tsx live
import React from 'react';
import { Pagination } from '@salutejs/plasma-homeds';

export function App() {
    return (
        <div style={{display: "flex", "flex-direction": "column"}}>
            <Pagination size="m" view="clear" slots={9} count={200} hasPerPage={true} />
        </div>
    );
}
```

### Вид активной кнопки Pagination
Вид Pagination задается с помощью свойства `viewCurrentPage`. Возможные значения свойства `viewCurrentPage`:
+ `"default"` – основная;
+ `"secondary"` – вторичная;
+ `"clear"` – чистая;

```tsx live
import React from 'react';
import { Pagination } from '@salutejs/plasma-homeds';

export function App() {
    return (
        <div style={{display: "flex", "flex-direction": "column"}}>
            <Pagination size="m" viewCurrentPage="default" slots={9} count={200} hasPerPage={true} />
            <Pagination size="m" viewCurrentPage="secondary" slots={9} count={200} hasPerPage={true} />
            <Pagination size="m" viewCurrentPage="clear" slots={9} count={200} hasPerPage={true} />
        </div>
    );
}
```

### Типы Pagination
Тип Pagination задается с помощью свойства `type`. Возможные значения свойства `type`:
+ `"default"` – обычная;
+ `"compact"` – компактная;

```tsx live
import React from 'react';
import { Pagination } from '@salutejs/plasma-homeds';

export function App() {
    return (
        <div style={{display: "flex", "flex-direction": "column"}}>
            <Pagination size="xs" type="default" slots={9} count={200} hasPerPage={true} />
            <Pagination size="xs" type="compact" slots={9} count={200} hasPerPage={true} />
        </div>
    );
}
```
