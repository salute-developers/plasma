# SDDS Portal — главная страница

Разводящая страница портала: первый экран с видео, команды на системе, живое окно
Builder, витрина продуктов, сцена «Builder — knowledge layer», разделы для тех,
кто уже работает с системой, и блок контактов.

## Структура

```
portal/landing/
  index.html      разметка страницы
  styles.css      все стили
  app.js          сценарии: скролл, витрина, граф подключений, выпуск версии
  lib/            lenis.min.js — плавный скролл
  media/          видео первого экрана, постер, зерно, иконки
  assets/         скриншоты продуктов для витрины
```

## Локальный запуск

```bash
node tools/landing-server.js
```

Откроется на `http://localhost:4200/`. Сервер поддерживает Range-запросы — без них
браузер считает видео неперематываемым.

## Что стоит знать при доработке

-   **Первый экран** — `hero-loop.mp4`: в файл уже вшит обратный ход (прямой проход
    плюс развёрнутая копия), поэтому достаточно обычного `loop`, без скриптов.
-   **Сцена подключений** (`#ai`) раскладывается из `app.js`: координаты связей
    считаются по фактическим прямоугольникам портов и пересчитываются при ресайзе.
    Светлый вариант включается классом `is-light` на `.kn-stage`.
-   **Акцент интерфейса** — токен `--accent`; зелёный остаётся только там, где он
    и есть содержание (палитра темы продукта в конфигураторе).
-   **Зерно** — отдельные файлы `noise.svg` и `noise-text.svg`: двусторонние, чтобы
    не сдвигать средний тон поверхности.
-   Стекло (`backdrop-filter`) оставлено только у панели, карточек метрик и
    наложений; у обычных карточек плотный фон — рядом с анимацией он давал
    мерцающие артефакты.

## Открытые вопросы

-   Сцена подключений скрывается при ширине до 1100px — вертикальной раскладки нет.
-   Цифры и подписи (80+, 1000+, версии, «бета») — черновые, нужны фактические.
-   Ссылки в карточках ведут на `#`.
