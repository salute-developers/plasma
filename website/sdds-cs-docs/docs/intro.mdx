# Библиотека компонентов для вертикали SDDS CS

Реализация компонентов для создания веб-приложений.

Компоненты реализованы с помощью [React](https://react.dev/) и поставляются в варианте на [emotion](https://emotion.sh/).

## Установка

:::info
Требуются `react` и `react-dom` версии `16.13.1` или выше, а также `@emotion/react` и `@emotion/styled` версии `11` или выше.
:::

```bash
$ npm install --save react react-dom
$ npm install --save @salutejs/sdds-cs @salutejs/sdds-themes
$ npm install --save @emotion/react @emotion/styled
```

## Варианты поставки

Единственный вариант поставки — [emotion](https://emotion.sh/).

| Точка входа          | Реализация | Дополнительные зависимости          |
| --------------------- | ---------- | ------------------------------------ |
| `@salutejs/sdds-cs`   | emotion    | `@emotion/react`, `@emotion/styled` |

```jsx
import { Button } from '@salutejs/sdds-cs';
```

Beta-компоненты доступны из точки входа `@salutejs/sdds-cs/beta`. Подробнее — в разделе [Beta](./beta/Popover.mdx).

## Использование компонентов

Все компоненты доступны напрямую из пакета:

```jsx
import { Button, BodyL } from '@salutejs/sdds-cs';

export const App = () => {
    return (
        <>
            <BodyL>Hello, SDDS CS!</BodyL>
            <Button>Кнопка</Button>
        </>
    );
};
```

## Использование токенов

Все `css` токены завернуты в `js` переменные для более удобного доступа:

```js
/** Основной цвет текста */
export const textPrimary = 'var(--text-primary, #F5F5F5)';
/** Основной фон */
export const backgroundPrimary = 'var(--background-primary, #000000)';
```

Так же в пакете есть типографические токены, для случаев, когда необходимо точечно применить типографику к контейнеру.

```js
/** Токены типографики для компонента DsplL */
export const dsplL = ({
    fontFamily: 'var(--plasma-typo-dspl-l-font-family)',
    fontSize: 'var(--plasma-typo-dspl-l-font-size)',
    fontStyle: 'var(--plasma-typo-dspl-l-font-style)',
    fontWeight: 'var(--plasma-typo-dspl-l-font-weight)',
    letterSpacing: 'var(--plasma-typo-dspl-l-letter-spacing)',
    lineHeight: 'var(--plasma-typo-dspl-l-line-height)',
} as unknown) as CSSObject;
```

Есть два пути импорта токенов:

:::tip
Путь `@salutejs/sdds-themes/tokens/sdds_cs` следует использовать, когда нужны токены, которые есть только в этой теме.
:::

-   базовый набор — из `@salutejs/sdds-themes/tokens`
-   уникальные токены темы — из `@salutejs/sdds-themes/tokens/sdds_cs`

Пример использования:

```jsx
import React from 'react';
import styled from '@emotion/styled';
import { textAccent, backgroundPrimary, textL } from '@salutejs/sdds-themes/tokens';

const AppStyled = styled.div`
    padding: 2rem;
    color: ${textAccent};
    background-color: ${backgroundPrimary};
`;

const Container = styled.div`
    ${textL};
    margin: 1rem;
`;

const App = () => {
    return (
        <AppStyled>
            <Container>
                <span>Hello world</span>
            </Container>
        </AppStyled>
    );
};

export default App;
```
