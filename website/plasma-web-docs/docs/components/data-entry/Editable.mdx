# Editable

Редактируемый текст. Клик по тексту или по иконке включает правку на месте. Внешний вид задаёт компонент типографики в `textComponent`.

## Использование

Иконка передаётся в `icon`. Чтобы её цвет менялся при наведении, укажите `color="inherit"`. Отступ до иконки задаётся токеном `editableTokens.iconGap`.

```tsx live
import React from 'react';
import { BodyM, Editable, H2, H5, editableTokens } from '@salutejs/plasma-web';
import { EditOutline } from '@salutejs/sdds-icons/24';

export function App() {
    return (
        <div style={{ display: 'flex', flexDirection: 'column', gap: '1.5rem' }}>
            <Editable
                textComponent={H2}
                value="Заголовок"
                icon={<EditOutline width={38} height={38} color="inherit" />}
                style={{ [editableTokens.iconGap]: '8px' }}
            />
            <Editable
                textComponent={H5}
                value="Название документа"
                placeholder="Введите название"
                icon={<EditOutline width={24} height={24} color="inherit" />}
                style={{ [editableTokens.iconGap]: '6px' }}
            />
            <Editable
                textComponent={BodyM}
                value="Короткий текст"
                icon={<EditOutline width={20} height={20} color="inherit" />}
                style={{ [editableTokens.iconGap]: '6px' }}
            />
        </div>
    );
}
```

## Текст и подсказка

`value` задаёт текст. В `onChange` новая строка лежит в `event.target.textContent`. `placeholder` виден, пока поле пустое и не в фокусе.

```tsx live
import React, { useState } from 'react';
import { Editable, H5, editableTokens } from '@salutejs/plasma-web';
import { EditOutline } from '@salutejs/sdds-icons/24';

export function App() {
    const [text, setText] = useState('');

    return (
        <Editable
            textComponent={H5}
            value={text}
            placeholder="Введите название"
            icon={<EditOutline width={24} height={24} color="inherit" />}
            style={{ [editableTokens.iconGap]: '6px' }}
            onChange={(event) => setText(event.target.textContent || '')}
        />
    );
}
```

## Перенос строки

`multiline` переносит значение на новую строку, когда оно не помещается по ширине родителя. Enter завершает редактирование.

```tsx live
import React from 'react';
import { Editable, H5, editableTokens } from '@salutejs/plasma-web';
import { EditOutline } from '@salutejs/sdds-icons/24';

export function App() {
    return (
        <Editable
            multiline
            style={{ maxWidth: '20rem', [editableTokens.iconGap]: '6px' }}
            icon={<EditOutline width={24} height={24} color="inherit" />}
            textComponent={H5}
            value="Очень длинное название документа, которое не помещается в одну строку"
        />
    );
}
```
