# Spinner
<Description name="Spinner" />

:::caution Устаревшие свойства
Пропсы `width`, `height`, `color`, `deviceScale` и числовое значение `size` устарели и будут удалены.
Используйте `size` и `view`.
:::

## Быстрый старт

```tsx live
import React from 'react';
import { Spinner } from '@salutejs/sdds-insol-next';

export function App() {
    return (
        <Spinner size="m" view="accent" />
    );
}
```
