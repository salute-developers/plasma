# Typography
В состав входят компоненты, реализующие типографическую систему.
Они заменяют обычные HTML-теги, такие, как `h1`, `h2`, `h3`, `h4`, `p`, etc.

## Установка шрифта
Компоненты типографики используют фирменный шрифт **Roboto**.

```html
<html lang="ru">
    <head>
        <link
            href="https://fonts.googleapis.com/css2?family=Roboto:ital,wght@0,400..700;1,400..700&display=swap"
            rel="stylesheet"
        />
        <title>...</title>
    </head>
    <body>
        ...
    </body>
</html>
```

## Отступы
По умолчанию типографика поддерживает стандартные отступы.

## Переносы
По умолчанию в типографике слова переносятся по слогам.
Чтобы отключить данный функционал, необходимо установить свойство `breakWord` в значении `false`.

## Пробелы
По умолчанию в типографике если текст превышает ширину элемента, то слова будут переноситься по пробелам.
Чтобы запретить перенос по пробелам, необходимо установить свойство `noWrap` в значении `true`.

## Смена тега
Если при использовании компонентов необходимо сменить тег, то можно использовать свойство `as`:

```tsx live
import React from 'react';
import { BodyM } from '@salutejs/sdds-sbcom';

export function App() {
    return (
        <BodyM as="h3">
            BodyM
        </BodyM>
    );
}
```

## Управление насыщенностью шрифта

:::info
Для корректной работы насыщенности шрифта убедитесь, что в конфигурациях типографических компонентов указаны соответствующие значения для `font-weight`.
:::

За это отвечают свойства: medium, bold, extraBold

```tsx live
import React from 'react';
import { DsplS } from '@salutejs/sdds-sbcom';

export function App() {
    return (
        <>
            <DsplS bold={false}>Regular</DsplS>
            <DsplS medium>Medium</DsplS>
            <DsplS>Bold</DsplS>
        </>
    )
}
```

## Курсивное начертание текста

Задается свойством `isItalic`.

```tsx live
import React from 'react';
import { DsplS } from '@salutejs/sdds-sbcom';

export function App() {
    return (
        <>
            <DsplS isItalic>Bold</DsplS>
        </>
    )
}
```

## Моноширинные числа (группа Numbers)
Для работы с типографическим компонентом из группы Numbers, достаточно указать свойство: `isNumeric`.

```tsx
<BodyS isNumeric={true} />
```

## Состав

### Hero unit

```tsx live
import React from 'react';
import { DsplS } from '@salutejs/sdds-sbcom';

export function App() {
    return (
        <div style={{ display: 'block' }}>
            <DsplS bold={false}>DsplS</DsplS>
            <DsplS>DsplS Bold</DsplS>
            <DsplS medium>DsplS Medium</DsplS>
        </div>
    );
}
```

### Заголовки

```tsx live
import React from 'react';
import { H1, H2, H3, H4 } from '@salutejs/sdds-sbcom';

export function App() {
    return (
        <div style={{ display: 'block' }}>
            <H1 bold={false}>H1</H1>
            <H1>H1 Bold</H1>
            <H1 medium>H1 Medium</H1>

            <H2 bold={false}>H2</H2>
            <H2>H2 Bold</H2>
            <H2 medium>H2 Medium</H2>

            <H3 bold={false}>H3</H3>
            <H3>H3 Bold</H3>
            <H3 medium>H3 Medium</H3>

            <H4 bold={false}>H4</H4>
            <H4>H4 Bold</H4>
            <H4 medium>H4 Medium</H4>
        </div>
    );
}
```

### Интерфейсы
Типографика для таких частей интерфейса, как button, label, подписи, и т.п.

```tsx live
import React from 'react';
import { BodyL, BodyM, BodyS, BodyXS, BodyXXS } from '@salutejs/sdds-sbcom';

export function App() {
    return (
        <div style={{ display: 'block' }}>
            <BodyL>BodyL</BodyL>
            <BodyL bold>BodyL Bold</BodyL>
            <BodyL medium>BodyL Medium</BodyL>

            <BodyM>BodyM</BodyM>
            <BodyM bold>BodyM Bold</BodyM>
            <BodyM medium>BodyM Medium</BodyM>

            <BodyS>BodyS</BodyS>
            <BodyS bold>BodyS Bold</BodyS>
            <BodyS medium>BodyS Medium</BodyS>

            <BodyXS>BodyXS</BodyXS>
            <BodyXS bold>BodyXS Bold</BodyXS>
            <BodyXS medium>BodyXS Medium</BodyXS>

            <BodyXXS>BodyXXS</BodyXXS>
            <BodyXXS bold>BodyXXS Bold</BodyXXS>
            <BodyXXS medium>BodyXXS Medium</BodyXXS>

            <BodyXXXS>BodyXXS</BodyXXXS>
            <BodyXXXS bold>BodyXXS Bold</BodyXXXS>
            <BodyXXXS medium>BodyXXS Medium</BodyXXXS>
        </div>
    );
}
```
