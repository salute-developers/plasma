## Быстрый старт

```tsx live
import React from 'react';
import { Chip } from '@salutejs/sdds-finai';
import { IconDownload } from '@salutejs/plasma-icons';

export function App() {
    return (
        <div style={{ display: 'flex', gap: '1rem', flexWrap: 'wrap' }}>
            <Chip text="Текст" />

        </div>
    );
}
```

## Контент

Компонент `Chip` может содержать текст, который указывается в свойстве `text`, или любой контент напрямую через `children`.

Свойство `text` можно использовать вместе со свойствами `contentLeft` и `contentRight` — с их помощью можно разместить **иконку** слева или справа от текста.

Иконку кнопки закрытия можно заменить через свойство `contentClearButton`, а отключить её отображение — свойством `hasClear`:

```tsx live
import React from 'react';
import { Chip } from '@salutejs/sdds-finai';
import { IconDownload } from '@salutejs/plasma-icons';

export function App() {
    return (
        <div style={{ display: 'flex', gap: '1rem', flexWrap: 'wrap' }}>
            <Chip text="Текст" />
            <Chip text="Текст" contentLeft={<IconDownload color="inherit" />} />
            <Chip contentLeft={<IconDownload color="inherit" />} />
            <Chip>Текст</Chip>
            <Chip text="Текст" hasClear={false} />
        </div>
    );
}
```

Свойство `onClickClose` позволяет обработать нажатие на иконку закрытия, например, чтобы удалить чип:

```tsx live
import React, { useState } from 'react';
import { Chip } from '@salutejs/sdds-finai';

export function App() {
    const [visible, setVisible] = useState(true);

    return visible ? <Chip text="Удали меня" onClickClose={() => setVisible(false)} /> : null;
}
```

## Скругления

Скругления `Chip` задаются свойствами `pilled` и `pin`. Если задано `pin`, оно имеет приоритет над `pilled`.

<Tabs>
    <TabItem value="pilled" label="pilled" default>

## Градиентный текст

Текст чипа можно окрасить в градиентный цвет с помощью класса `sdds-core-text-node`:

```tsx live
import React from 'react';
import { Chip } from '@salutejs/sdds-finai';
import styled from 'styled-components';

export function App() {
    const GradientChip = styled(Chip)`
        & .sdds-core-text-node {
            background: linear-gradient(90deg, #f7971e, #ffd200);
            background-clip: text;
            -webkit-background-clip: text;
            -webkit-text-fill-color: transparent;
        }
    `;

    return (
        <div style={{ display: 'flex', gap: '1rem', flexWrap: 'wrap' }}>
            <GradientChip text="Градиент" />
        </div>
    );
}
```

## Состояния

Компонент поддерживает состояния `disabled` и `readOnly`:

```tsx live
import React from 'react';
import { Chip } from '@salutejs/sdds-finai';

export function App() {
    return (
        <div style={{ display: 'flex', gap: '1rem' }}>
            <Chip text="Активный" />
            <Chip text="Неактивный" disabled />
            <Chip text="Только чтение" readOnly />
        </div>
    );
}
```
