# ChipGroup
<Description name="ChipGroup" />

## Быстрый старт

Компонент `ChipGroup` — это обёртка для `Chip`, принимает в себя группу элементов:

```tsx live
import React from 'react';
import { ChipGroup, Chip } from '@salutejs/sdds-finai';

export function App() {
    return (
        <ChipGroup>
            {Array(5)
                .fill(true)
                .map((_, i) => (
                    <Chip text={`Chip ${i}`} />
                ))}
        </ChipGroup>
    );
}
```

## Управление внешним видом

Размер и вид группы элементов задаются свойствами `size` и `view`. Свойство `isCommonChipStyles` (по умолчанию `true`) включает переопределение стилей для всех `Chip` внутри группы значениями группы — если отключить его, каждый элемент может иметь свой размер и вид:

    <TabItem value="common" label="Общий стиль" default>

        ```tsx live
        import React from 'react';
        import { ChipGroup, Chip } from '@salutejs/sdds-finai';

            return (
                <ChipGroup size="s" view="secondary">

                        .fill(true)
                        .map((_, i) => (
                            <Chip text={`Chip ${i}`} />
                        ))}
                </ChipGroup>
            );
        }
        ```
    </TabItem>
    <TabItem value="custom" label="Индивидуальный стиль">
        ```tsx live
        import React from 'react';
        import { ChipGroup, Chip } from '@salutejs/sdds-finai';

        export function App() {
            return (
                <ChipGroup isCommonChipStyles={false}>
                    <Chip size="m" text="Default" />

                    <Chip size="xs" text="Accent" view="accent" />
                </ChipGroup>
        ```

## Отступы между Chip

Группа элементов имеет два вида отступов, задаваемых свойством `gap`:

```tsx live
import React from 'react';
import { ChipGroup, Chip } from '@salutejs/sdds-finai';

export function App() {
    return (
        <div style={{ display: 'flex', flexDirection: 'column', gap: '1rem' }}>
            <ChipGroup size="xs" gap="dense">
                {Array(5)
                    .fill(true)
                    .map((_, i) => (
                        <Chip text={`Chip ${i}`} />
                    ))}
            </ChipGroup>

            <ChipGroup size="xs" gap="wide">
                {Array(5)
                    .fill(true)
                    .map((_, i) => (
                        <Chip text={`Chip ${i}`} />
                    ))}
            </ChipGroup>
        </div>
    );
}
```

## Скругления группы

Скругления `Chip` внутри группы задаются свойством `shape`:

```tsx live
import React from 'react';
import { ChipGroup, Chip } from '@salutejs/sdds-finai';

export function App() {
    return (
        <div style={{ display: 'flex', flexDirection: 'column', gap: '1rem' }}>
            <ChipGroup size="xs" shape="default">
                {Array(3)
                    .fill(true)
                    .map((_, i) => (
                        <Chip text={`Chip ${i}`} />
                    ))}
            </ChipGroup>

            <ChipGroup size="xs" shape="segmented">
                {Array(3)
                    .fill(true)
                    .map((_, i) => (
                        <Chip text={`Chip ${i}`} />
                    ))}
            </ChipGroup>
        </div>
    );
}
```

## Перенос элементов

Свойство `isWrapped` включает перенос элементов на новую строку при нехватке ширины контейнера:

```tsx live
import React from 'react';
import { ChipGroup, Chip } from '@salutejs/sdds-finai';

export function App() {
    return (
        <div style={{ width: '20rem' }}>
            <ChipGroup isWrapped>
                {Array(10)
                    .fill(true)
                    .map((_, i) => (
                        <Chip text={`Chip ${i}`} />
                    ))}
            </ChipGroup>
        </div>
    );
}
```
