```jsx
import React from 'react';
import { Button, BodyL } from '@salutejs/sdds-finai/css';

import '@salutejs/sdds-themes/css/sdds_finai__light.css';

const App = () => {
    return (
        <>
            <BodyL>Hello world</BodyL>
            <Button text="This is themed button" />
        </>
    );
};

export default App;
```

Или подключите тему в файле, где собраны все стили приложения, например `index.css`

```css
@import '@salutejs/sdds-themes/css/sdds_finai__light.css';
```
