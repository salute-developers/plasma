# Markdown

Markdown отображает Markdown-разметку в ответах ассистента: заголовки, списки, ссылки, таблицы, код и другие элементы форматированного текста.
Поддерживает постепенное отображение незавершённого ответа.

## Быстрый старт

```tsx live
import React from 'react';
import { Markdown } from '@salutejs/sdds-serv/ai';

export function App() {
    return (
        <Markdown content={'## Ответ ассистента\nПоддерживаются **форматирование**, списки и `код`.'} />
    );
}
```
