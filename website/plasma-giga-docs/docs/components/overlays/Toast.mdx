# Toast

:::info
Обновлённая версия компонента Toast с поддержкой управления отдельными тостами, настакивания, кастомного рендера и анимации.
:::

## Использование

Вставьте `ToastContainer` один раз в дерево приложения, затем вызывайте `showToast` там, где нужно показать уведомление.
На этой странице все интерактивные примеры используют контейнер из первого примера.

```tsx live
import React from 'react';
import { Button, ToastContainer, showToast } from '@salutejs/plasma-giga';

export function App() {
    return (
        <>
            <ToastContainer />
            <Button
                text="Показать уведомление"
                onClick={() => showToast('Изменения сохранены')}
            />
        </>
    );
}
```

По умолчанию повторный вызов `showToast` заменяет текущий тост. Чтобы показывать несколько уведомлений одновременно, передайте `stacking: true`. Тосты складываются отдельно для каждой позиции, например `top-center` и `bottom-right`. Расстояние между тостами настраивается в пикселях через `gap` у `ToastContainer`; по умолчанию оно равно `8`.

```tsx live
import React from 'react';
import { Button, showToast } from '@salutejs/plasma-giga';

export function App() {
    const showAtTop = () =>
        showToast('Уведомление сверху', { stacking: true, position: 'top-center', duration: 3000 });
    const showAtBottomRight = () =>
        showToast('Уведомление справа снизу', { stacking: true, position: 'bottom-right', duration: 3000 });

    return (
        <>
            <Button text="Показать сверху" onClick={showAtTop} />
            <Button text="Показать справа снизу" onClick={showAtBottomRight} />
        </>
    );
}
```

`showToast` возвращает ID тоста. Его можно использовать, чтобы закрыть именно это уведомление с помощью `hideToast(id)`. Если передать собственный `id`, повторный вызов с тем же ID обновит этот тост. При `stacking: true` и без заданного ID он генерируется библиотекой.

```tsx
const id = showToast('Загрузка завершена', { stacking: true });
hideToast(id);
```

### Кастомный рендер

Для отдельного тоста можно передать `renderToast`. Callback получает опции этого тоста, включая итоговый ID. Текст можно использовать из замыкания:

```tsx live
import React from 'react';
import { Button, showToast } from '@salutejs/plasma-giga';

export function App() {
    const message = 'Профиль обновлён';

    return (
        <>
            <Button
                text="Показать кастомный тост"
                onClick={() =>
                    showToast(message, {
                        stacking: true,
                        position: 'bottom-right',
                        duration: 3000,
                        renderToast: (options) => (
                            <div style={{ padding: '12px 16px', borderRadius: 12, background: '#252525', color: '#fff' }}>
                                <strong>{message}</strong>
                                <div>ID: {options?.id}</div>
                            </div>
                        ),
                    })
                }
            />
        </>
    );
}
```

### Анимация

Задайте CSS keyframes в стилях приложения. Общую анимацию можно передать в `ToastContainer` через `animation`, а анимацию отдельного тоста — через `showToast`.

```tsx live
import React from 'react';
import { Button, showToast } from '@salutejs/plasma-giga';

export function App() {
    return (
        <>
            <style>{`
                @keyframes toast-enter-from-right {
                    from { opacity: 0; transform: translateX(1.5rem); }
                    to { opacity: 1; transform: translateX(0); }
                }

                @keyframes toast-exit-to-right {
                    from { opacity: 1; transform: translateX(0); }
                    to { opacity: 0; transform: translateX(1.5rem); }
                }

                @keyframes toast-enter-from-bottom {
                    from { opacity: 0; transform: translateY(1.5rem); }
                    to { opacity: 1; transform: translateY(0); }
                }

                @keyframes toast-exit-to-bottom {
                    from { opacity: 1; transform: translateY(0); }
                    to { opacity: 0; transform: translateY(1.5rem); }
                }
            `}</style>
            <Button
                text="Выезд справа"
                onClick={() =>
                    showToast('Тост въезжает справа', {
                        stacking: true,
                        position: 'bottom-right',
                        duration: 3000,
                        animation: {
                            enter: 'toast-enter-from-right 300ms ease-out both',
                            exit: 'toast-exit-to-right 200ms ease-in both',
                        },
                    })
                }
            />
            <Button
                text="Выезд снизу"
                onClick={() =>
                    showToast('Тост въезжает снизу', {
                        stacking: true,
                        position: 'bottom-right',
                        duration: 3000,
                        animation: {
                            enter: 'toast-enter-from-bottom 300ms ease-out both',
                            exit: 'toast-exit-to-bottom 200ms ease-in both',
                        },
                    })
                }
            />
        </>
    );
}
```

## API

### Свойства `ToastContainer`

<PropsTable name="ToastContainer" />

### Свойства `showToast`

| Свойство | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `stacking` | `boolean` | `false` | Разрешает показывать несколько тостов одновременно. |
| `id` | `string` | Автоматический при `stacking: true` | ID тоста. Возвращается из `showToast`; используется в `hideToast`. |
| `position` | `ToastPosition` | `bottom-center` | Позиция тоста. Для каждой позиции создаётся отдельная стопка. |
| `duration` | `number` | `Infinity` | Время отображения в миллисекундах. |
| `animation` | `{ enter?: CSSProperties['animation']; exit?: CSSProperties['animation'] }` | Анимация `react-hot-toast` | CSS-анимации появления и скрытия. Настройка в опциях `showToast` переопределяет значение `ToastContainer`. |
| `renderToast` | `(options?: Omit<ShowToastPlasmaOptions, 'renderToast'>) => ReactNode` | — | Функция для кастомного рендера тоста. |
| `hasClose` | `boolean` | `true` | Показывает кнопку закрытия стандартного тоста. |
| `contentLeft` | `ReactNode` | — | Контент слева от текста стандартного тоста. |
| `width` | `CSSProperties['width']` | `auto` | Ширина стандартного тоста. |
| `textColor` | `CSSProperties['color']` | Из `view` | Цвет текста стандартного тоста. |
| `view`, `size`, `pilled` | `string`, `string`, `boolean` | Из конфига темы | Вариант, размер и скруглённая форма стандартного тоста. |
