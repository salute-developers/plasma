MCP-сервер `@salutejs/sdds-mcp` даёт ИИ-агенту (Claude Code, Cursor, VS Code и другим) доступ к актуальной документации `plasma-giga`. Без него агент пишет код по памяти и может перепутать названия компонентов и свойств.

После подключения ничего делать не нужно: агент сам обращается к документации, когда ему нужна информация о библиотеке. Вы задаёте вопросы обычным текстом.

:::info
Сервер поддерживает `@salutejs/plasma-giga` начиная с версии `0.338.0`. Для более старых версий - сервис недоступен.
:::

## Быстрый старт

Сервер запускается локально одной командой. Нужен Node.js 18 или новее.

```bash
npx -y @salutejs/sdds-mcp@latest --lib plasma-giga
```

Как подключить сервер, зависит от агента:

<Tabs>
<TabItem value="claude-code" label="Claude Code" default>

```bash
claude mcp add plasma-giga -- npx -y @salutejs/sdds-mcp@latest --lib plasma-giga
```

Добавьте флаг `--scope project`, если сервер нужен всем участникам проекта: настройка сохранится в файле `.mcp.json` в корне репозитория.

</TabItem>
<TabItem value="cursor" label="Cursor">

Добавьте в файл `.cursor/mcp.json` проекта или в глобальный `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "plasma-giga": {
      "command": "npx",
      "args": ["-y", "@salutejs/sdds-mcp@latest", "--lib", "plasma-giga"]
    }
  }
}
```

</TabItem>
<TabItem value="vscode" label="VS Code">

Добавьте в файл `.vscode/mcp.json`:

```json
{
  "servers": {
    "plasma-giga": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@salutejs/sdds-mcp@latest", "--lib", "plasma-giga"]
    }
  }
}
```

</TabItem>
<TabItem value="other" label="Другой агент">

Если агент просит указать `command` и `args` отдельно, используйте такой шаблон:

```json
{
  "mcpServers": {
    "plasma-giga": {
      "command": "npx",
      "args": ["-y", "@salutejs/sdds-mcp@latest", "--lib", "plasma-giga"]
    }
  }
}
```

</TabItem>

## Что можно спрашивать у агента

Результат лучше, если назвать библиотеку и описать задачу.

-   **Разобраться в библиотеке:** `Какие компоненты есть в plasma-giga?`, `Какие props есть у Button? Какие значения принимает view?`, `Приведи примеры использования TextField`.
-   **Сверстать экран:** `Сверстай форму входа на компонентах plasma-giga с валидацией через React Hook Form`, `Подбери иконку для кнопки удаления`.
-   **Начать проект:** `Как установить plasma-giga и подключить тему?`, `Покажи, как подключить plasma-giga в Next.js`.
-   **Стилизовать своё:** `Покажи токены, которые можно использовать в кастомном компоненте`, `Каким токеном задать цвет второстепенного текста?`.

## Инструменты

Инструменты — это запросы к документации, которые агент выполняет сам. Знать их названия не обязательно, но по таблице видно, что агенту доступно.

| Инструмент                                          | Назначение                                                 | Параметры        |
|-----------------------------------------------------|------------------------------------------------------------|------------------|
| [`list_components`](#list_components)               | Список всех компонентов с кратким описанием.               | —                |
| [`search_icons`](#search_icons)                     | Поиск иконок `@salutejs/sdds-icons`.                       | `query`, `limit` |
| [`get_installation_guide`](#get_installation_guide) | Установка библиотеки, подключение темы, шрифтов и токенов. | —                |
| [`get_nextjs_guide`](#get_nextjs_guide)             | Подключение библиотеки в Next.js.                          | —                |
| [`get_form_guide`](#get_form_guide)                 | Работа с формами: нативные формы и React Hook Form.        | —                |
| [`get_tokens`](#get_tokens)                         | Дизайн-токены для стилизации своих компонентов.            | —                |
| [`get_component`](#get_component)                   | Описание, свойства и примеры кода компонента.              | `name`           |

### `list_components`

Возвращает названия всех компонентов библиотеки и одно предложение о каждом. С него агент обычно начинает: выбирает подходящие компоненты, а затем запрашивает их подробности через `get_component`.

**Параметры:** нет.

### `search_icons`

Ищет иконки по названию и ключевым словам на русском и английском, например `корзина` или `arrow`. Возвращает имя компонента иконки, ключевые слова и доступные размеры (`16`, `24`, `36`). Иконка импортируется из `@salutejs/sdds-icons/<размер>`.

**Параметры:**

| Параметр | Тип       | Обязательный | Описание                                                        |
|----------|-----------|--------------|-----------------------------------------------------------------|
| `query`  | `string`  | да           | Название иконки или описание её смысла.                         |
| `limit`  | `integer` | нет          | Сколько результатов вернуть: от `1` до `50`, по умолчанию `20`. |

### `get_installation_guide`

Возвращает стартовое руководство: как установить пакет, какие есть варианты поставки, как подключить тему и шрифты, переключать светлую и тёмную тему, использовать компоненты и токены.

**Параметры:** нет.

### `get_nextjs_guide`

Возвращает руководство по Next.js: поддержка серверных компонентов через `'use client'`, подключение тем и примеры для styled-components и CSS.

**Параметры:** нет.

### `get_form_guide`

Возвращает все руководства по формам: обычная HTML-форма и валидация, интеграция с React Hook Form, особенности отдельных компонентов в формах, например Slider и DatePicker.

**Параметры:** нет.

### `get_tokens`

Возвращает список токенов темы с пояснением, за что каждый отвечает: цвета, градиенты, типографика, скругления. С ними агент стилизует кастомные элементы в стиле дизайн-системы вместо значений, заданных вручную. Токены импортируются из `@salutejs/plasma-themes/tokens`.

**Параметры:** нет.

### `get_component`

Возвращает всё со страницы компонента в документации: описание, список свойств с типами и примеры кода. Регистр в имени не важен: `button` и `Button` дадут один результат. Если компонента с таким именем нет, агент получит список доступных имён и сможет выбрать подходящее.

**Параметры:**

| Параметр | Тип      | Обязательный | Описание                                                |
|----------|----------|--------------|---------------------------------------------------------|
| `name`   | `string` | да           | Название компонента, например `Button` или `TextField`. |

## Если что-то не работает

-   **Сервер не запускается.** Проверьте версию Node.js и доступ к `plasma.sberdevices.ru`: документация загружается оттуда.
-   **Агент описывает не те компоненты.** Проверьте, что в команде есть `--lib plasma-giga`: без этого флага сервер отдаёт документацию `plasma-web`.
-   **Свойства не совпадают с вашей версией библиотеки.** По умолчанию сервер отдаёт документацию последней версии. Добавьте в команду `--version` с версией `@salutejs/plasma-giga` из вашего `package.json`:

    ```bash
    npx -y @salutejs/sdds-mcp@latest --lib plasma-giga --version 0.371.0
    ```

    Если указанной версии нет, сервер использует последнюю.
