## Использование
Компонент `Checkbox` может содержать лейбл и описание.

```tsx live
import React from 'react';
import { Checkbox } from '@salutejs/plasma-b2c';

export function App() {
    return (
        <Checkbox label="Чекбокс" description="Описание" defaultChecked />
    );
}
```

Свойства `description` и `label` могут принимать JSX элементы.

По умолчанию, контент внутри лейбла и описания многострочный.

Для того чтобы стал однострочным, необходимо использовать свойство `singleLine`(по умолчанию `false`).

```tsx live
import React from 'react';
import { Checkbox } from '@salutejs/plasma-b2c';

export function App() {
    return (
        <Checkbox
            label={<div>Чекбокс со <a href="/#">ссылкой</a></div>}
            description={<div>Описание чекбокса со <a href="/#">ссылкой</a></div>}
        />
    );
}

```

Состояние `indeterminate` имеет приоритет и не зависит от свойства `checked`

```tsx live
import React from 'react';
import { Checkbox } from '@salutejs/plasma-b2c';

export function App() {
    return (
        <Checkbox label="Чекбокс" description="Описание" defaultChecked indeterminate checked={false} />
    );
}
```

## Группа чекбоксов

Для группы чекбоксов, в том числе с вложенностью, используйте `List` и `ListItem`.

```tsx live
import { useState } from 'react';
import { Checkbox, List, ListItem } from '@salutejs/plasma-b2c';

export function App() {
    const items = [
        { value: 'russian', label: 'Русский', description: 'Родной язык для 150 млн человек' },
        { value: 'english', label: 'Английский', description: 'Самый распространённый язык в мире' },
        { value: 'french', label: 'Французский' },
        { value: 'chinese', label: 'Китайский' },
    ];

    const [values, setValues] = useState({ russian: true, english: true });

    const checkedCount = items.filter((item) => values[item.value]).length;
    const isAllChecked = checkedCount === items.length;
    const isIndeterminate = checkedCount > 0 && !isAllChecked;

    const onParentChange = (event) => {
        const { checked } = event.target;

        setValues(items.reduce((acc, item) => ({ ...acc, [item.value]: checked }), values));
    };

    const onChildChange = (value) => (event) => setValues({ ...values, [value]: event.target.checked });

    return (
        <List role="group" aria-label="Языки" variant="tight">
            <ListItem tabIndex={-1}>
                <Checkbox
                    label="Языки"
                    description={`Выбрано: ${checkedCount} из ${items.length}`}
                    checked={isAllChecked}
                    indeterminate={isIndeterminate}
                    onChange={onParentChange}
                />
            </ListItem>
            {items.map((item) => (
                <ListItem key={item.value} tabIndex={-1} style={{ paddingLeft: 36 }}>
                    <Checkbox
                        label={item.label}
                        description={item.description}
                        checked={Boolean(values[item.value])}
                        onChange={onChildChange(item.value)}
                    />
                </ListItem>
            ))}
        </List>
    );
}
```
