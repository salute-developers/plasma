## Примеры

### Строковое значение

Если `count` передан как строка, значение отображается без изменений. Ограничения по минимальному и максимальному значению, а также автоматическая круглая форма применяются только к числам. Свойство `maxCount` для строки игнорируется.

```tsx live
import React from 'react';
import { Counter } from '@salutejs/sdds-insol';

export function App() {
    return (
        <div>
            <Counter count="NEW" />
            <Counter count="100+" maxCount={1} />
        </div>
    );
}
```

### Максимальное значение числового бейджа
Задается с помощью свойства `maxCount` и применяется только к числовому `count`. Не может быть меньше 1.

```tsx live 
import React from 'react';
import { Counter } from '@salutejs/sdds-insol';

export function App() {
    return (
        <div>
            <Counter count={10} maxCount={9} />
            <Counter count={100} maxCount={99} />
        </div>
    );
}
```

### Размер числового бейджа
Размер задается с помощью свойства `size`. Возможные значения свойства: `"xs"` или `"xxs"`.

```tsx live 
import React from 'react';
import { Counter } from '@salutejs/sdds-insol';

export function App() {
    return (
        <div>
            <Counter count={10} size="xs" />
            <Counter count={10} size="xxs" />
        </div>
    );
}
```

### Вид числового бейджа
Вид задается с помощью свойства `view`. Возможные значения свойства `view`:

+ `"default"` – основной бейдж;
+ `"accent"` – бейдж акцентного цвета;
+ `"positive"` – успешное завершение;
+ `"warning"` – предупреждение;
+ `"negative"` – ошибка;
+ `"dark"` – темный бэйдж;
+ `"light"` – светлый бэйдж.

```tsx live 
import React from 'react';
import { Counter } from '@salutejs/sdds-insol';

export function App() {
    return (
        <div>
            <Counter count={10} view="default" />
            <Counter count={10} view="accent" />
            <Counter count={10} view="positive" />
            <Counter count={10} view="warning" />
            <Counter count={10} view="negative" />
            <Counter count={10} view="dark" />
            <Counter count={10} view="light" />
        </div>
    );
}
```
