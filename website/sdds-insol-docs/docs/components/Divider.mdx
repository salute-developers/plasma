## Использование
Компонент `Divider` используется для визуального разделения компонент.

### Ориентация разделителя
Ориентация разделителя задается с помощью свойства orientation.

Возможные значения свойства orientation:
+ "horizontal" – горизонтальная (по умолчанию);
+ "vertical" – вертикальная;

```tsx live
import React from 'react';
import { BodyS, Divider } from '@salutejs/sdds-insol';

export function App() {
    const Demo = ({
        orientation = 'horizontal',
        length = '100%',
        beforeText = 'Before',
        afterText = 'After',
    }) => {
        const wrapperStyle = {
            display: "inline-flex",
            gap: "0.5rem",
            alignItems: "center",
            justifyContent: "center",
            flexDirection: orientation === "horizontal" ? "column" : "row"
        }

        return (
            <div style={wrapperStyle}>
                <BodyS>{beforeText}</BodyS>
                <Divider orientation={orientation} length={length} />
                <BodyS>{afterText}</BodyS>
            </div>
        );
    };

    return (
        <div style={{ display: "flex", gap: "2rem" }}>
            <Demo />
            <Demo orientation="vertical" />
        </div>
    );
}
```

### Цвет разделителя
Цвет разделителя можно изменить с помощью свойства `color`:

```tsx live
import React from 'react';
import { Divider } from '@salutejs/sdds-insol';
import { surfacePositive, surfaceNegative } from '@salutejs/sdds-themes/tokens/sdds_insol';

export function App() {
    return (
        <div style={{ display: 'flex', gap: '2rem', alignItems: 'center', height: '4rem' }}>
            <Divider orientation="horizontal" length="10rem" color={surfacePositive} />
            <Divider orientation="vertical" length="4rem" color={surfaceNegative} />
        </div>
    );
}
```
