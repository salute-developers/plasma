# Spinner
<Description name="Spinner" />
<PropsTable name="Spinner" exclude={['css', 'focused']}/>

:::caution Устаревшие свойства
Свойства `width`, `height`, `color` и `deviceScale` оставлены для обратной совместимости и будут удалены.
Для настройки размера и цвета используйте `size` и `view`.
:::

:::caution Устаревшие значения свойства view
Значения `tertiary` и `paragraph` устарели и будут удалены в будущих версиях.
:::

## Быстрый старт

```tsx live
import React from 'react';
import { Spinner } from '@salutejs/sdds-dfa';

export function App() {
    return (
        <Spinner size="m" view="accent" />
    );
}
```

## Управление внешним видом

Внешний вид компонента задаётся свойствами `view` и `size`:

<Tabs>
    <TabItem value="view" label="View" default>
        Возможные значения свойства `view`:

        + `"default"` – по умолчанию;
        + `"secondary"` – вторичный;
        + `"tertiary"` – третичный;
        + `"paragraph"` – для основного текста;
        + `"accent"` – акцентный;
        + `"positive"` – успешное завершение;
        + `"warning"` – предупреждение;
        + `"negative"` – ошибка;
        + `"info"` – информационный.

        ```tsx live
        import React from 'react';
        import { Spinner } from '@salutejs/sdds-dfa';

        export function App() {
            return (
                <div style={{ display: 'flex', alignItems: 'center', gap: '1.5rem' }}>
                    <Spinner view="default" />
                    <Spinner view="secondary" />
                    <Spinner view="tertiary" />
                    <Spinner view="paragraph" />
                    <Spinner view="accent" />
                    <Spinner view="positive" />
                    <Spinner view="warning" />
                    <Spinner view="negative" />
                    <Spinner view="info" />
                </div>
            );
        }
        ```
    </TabItem>
    <TabItem value="size" label="Size">
        Возможные значения свойства `size`: `"xxs"`, `"xs"`, `"s"`, `"m"`, `"l"`, `"xl"`, `"xxl"`.

        ```tsx live
        import React from 'react';
        import { Spinner } from '@salutejs/sdds-dfa';

        export function App() {
            return (
                <div style={{ display: 'flex', alignItems: 'center', gap: '1.5rem' }}>
                    <Spinner size="xxs" />
                    <Spinner size="xs" />
                    <Spinner size="s" />
                    <Spinner size="m" />
                    <Spinner size="l" />
                    <Spinner size="xl" />
                    <Spinner size="xxl" />
                </div>
            );
        }
        ```
    </TabItem>
