# GroupIconButton
<Description name="GroupIconButton" />

## Использование
Компонент `GroupIconButton` - это обертка для IconButton. Принимает в себя группу кнопок.

```tsx live
import React from 'react';
import { GroupIconButton, IconButton } from '@salutejs/sdds-dfa';
import { IconClose } from '@salutejs/plasma-icons';

export function App() {
    return (
        <GroupIconButton>
            {Array(5)
                .fill(true)
                .map((_, i) => (
                    <IconButton><IconClose color="inherit" size="s" /></IconButton>
                ))}
        </GroupIconButton>
    );
}
```

## Примеры

### Размер и вид группы кнопок
Размер и вид группы кнопок задается с помощью свойств `size` и `view` соответственно.
С помощью свойства `isCommonButtonStyles` можно отключить переопределение стилей для всех кнопок внутри группы.
Тогда каждая кнопка будет иметь настраиваемый размер и вид.

Возможные значения свойства `view`: `"default"`, `"accent"`, `"secondary"`, `"clear"`, `"positive"`, `"warning"`, `"negative"`, `"dark"`, `"black"`, `"white"`, `"success"`, `"critical"`.

Возможные значения свойства `size`: `"l"`, `"m"`, `"s"`, `"xs"`, `"xxs"`, `"xl"`.

:::caution
Значения `"success"` и `"critical"` свойства `view` устарели и будут удалены в будущих версиях.
Используйте `"positive"` вместо `"success"` и `"negative"` вместо `"critical"`.

Значение `"xl"` свойства `size` устарело и будет удалено в будущих версиях. Используйте `"l"`.
:::

```tsx live
import React from 'react';
import { GroupIconButton, IconButton } from '@salutejs/sdds-dfa';
import { IconClose } from '@salutejs/plasma-icons';

export function App() {
    return (
        <div>
            <GroupIconButton size="s" view="secondary">
                {Array(5)
                    .fill(true)
                    .map((_, i) => (
                        <IconButton><IconClose color="inherit" size="s" /></IconButton>
                    ))}
            </GroupIconButton>

            <GroupIconButton isCommonButtonStyles={false}>
                <IconButton size="m"><IconClose color="inherit" size="s" /></IconButton>
                <IconButton size="s" view="positive"><IconClose color="inherit" size="s" /></IconButton>
                <IconButton size="xs" view="negative"><IconClose color="inherit" size="s" /></IconButton>
            </GroupIconButton>
        </div>
    );
}
```

### Ориентация группы кнопок и отступы между кнопками

Группа может располагаться вертикально или горизонтально и иметь три вида отступов. Для `shape="default"` и `shape="pilled"` значение `gap="dense"` равно 4px. Для `shape="segmented"` — 2px.

```tsx live
import React from 'react';
import { GroupIconButton, IconButton } from '@salutejs/sdds-dfa';
import { IconClose } from '@salutejs/plasma-icons';

export function App() {
    return (
        <div>
            <GroupIconButton size="xs" orientation="vertical" gap="none">
                {Array(5)
                    .fill(true)
                    .map((_, i) => (
                        <IconButton><IconClose color="inherit" size="s" /></IconButton>
                    ))}
            </GroupIconButton>

            <GroupIconButton size="xs" orientation="horizontal" gap="wide">
                {Array(4)
                    .fill(true)
                    .map((_, i) => (
                        <IconButton><IconClose color="inherit" size="s" /></IconButton>
                    ))}
            </GroupIconButton>
        </div>
    );
}
```

### Границы кнопки
Границы кнопки задаются с помощью свойства `shape`.

```tsx live
import React from 'react';
import { GroupIconButton, IconButton } from '@salutejs/sdds-dfa';
import { IconClose } from '@salutejs/plasma-icons';

export function App() {
    return (
        <div>
            <GroupIconButton size="xs" shape="segmented">
                {Array(3)
                    .fill(true)
                    .map((_, i) => (
                        <IconButton><IconClose color="inherit" size="s" /></IconButton>
                    ))}
            </GroupIconButton>

            <GroupIconButton size="xs" shape="default">
                {Array(3)
                    .fill(true)
                    .map((_, i) => (
                        <IconButton><IconClose color="inherit" size="s" /></IconButton>
                    ))}
            </GroupIconButton>

            <GroupIconButton size="xs" shape="pilled">
                {Array(3)
                    .fill(true)
                    .map((_, i) => (
                        <IconButton><IconClose color="inherit" size="s" /></IconButton>
                    ))}
            </GroupIconButton>
        </div>
    );
}
```
