# Combobox

<Description name="Combobox" />

## Использование
Обязательным параметром является только `items`. Внутри items может быть такой же вложенный массив items. Формат следующий:

```tsx
type Items = Array<{
    /**
     * Значение у item.
     */
    value: string;
    /**
     * Метка-подпись к item.
     */
    label: string;
    /**
     * Сторона открытия вложенного дропдауна относительно текущего элемента.
     * @default bottom-start
     */
    placement?: Placement;
    /**
     * Список дочерних items.
     */
    items?: Array<ItemOption>;
    /**
     * Item не активен.
     */
    disabled?: boolean;
    /**
     * Слот для контента слева.
     */
    contentLeft?: ReactNode;
    /**
     * Слот для контента справа.
     */
    contentRight?: ReactNode;
    /**
     * Classname для item.
     */
    className?: string;
    /**
     * Максимальная высота дочернего выпадающего списка.
     */
    listMaxHeight?: CSSProperties['height'];
}>;
```

Тип выбора задается свойством `multiple`. В одиночном режиме `value` и `defaultValue` имеют тип `string`, в множественном - `string[]`.

В одиночном режиме можно использовать `mode="radio"`, если нужно запретить снятие выбора повторным кликом. В множественном режиме доступны `selectAllOptions`, `isTargetAmount`, `targetAmount`, `renderValue` и `chipClickArea`.

    <TabItem value="infinite" label="Infinite Loading">
        Пример с бесконечной загрузкой элементов в списке.

       ```tsx live
        import React, { useState } from 'react';
        import { Combobox } from '@salutejs/sdds-dfa';

        export function App() {
            function getRandomData() {
                return Array(10)
                    .fill(1)
                    .map(() => {
                        const n = Math.floor(Math.random() * 90000000) + 10000000;
                        return { value: n.toString(), label: n.toString() };
                    });
            };

            const [items, setItems] = useState(getRandomData());
            const [isInfiniteLoading, setIsInfiniteLoading] = useState(false);

            const getData = async () => {
                return new Promise((resolve) => {
                    setTimeout(() => {
                        resolve(getRandomData());
                    }, 1500);
                });
            };

            const handleScroll = async (e) => {
                if (isInfiniteLoading) return;

                if (e.currentTarget.scrollTop + e.currentTarget.offsetHeight + 10 > e.currentTarget.scrollHeight) {
                    setIsInfiniteLoading(true);

                    const res = await getData();

                    setItems([...items, ...res]);

                    setIsInfiniteLoading(false);
                }
            };

            return (
                <div style={{ height: "300px" }}>
                    <div style={{ width: "300px" }}>
                        <Combobox
                            items={items}
                            listMaxHeight="200px"
                            placeholder="Placeholder"
                            label="Label"
                            helperText="Helper text"
                            onScroll={handleScroll}
                            afterList={isInfiniteLoading ? <center>Загружаю...</center> : undefined}
                        />
                    </div>
                </div>
            );
        }
        ```

        Работа с кнопкой "Выбрать всё" осуществляется через свойство `selectAllOptions` только в режиме `multiple`:

        Вся логика выбора элементов и взаимодействия с компонентом лежит на стороне пользователя.

        ```tsx live
        import React, { useState, useEffect } from 'react';
        import { Combobox } from '@salutejs/sdds-dfa';

        export function App() {
            const flatItems = [
                {
                    value: 'north_america',
                    label: 'Северная Америка',
                },
                {
                    value: 'rio_de_janeiro',
                    label: 'Рио-де-Жанейро',
                },
                {
                    value: 'sao_paulo',
                    label: 'Сан-Паулу',
                },
                {
                    value: 'buenos_aires',
                    label: 'Буэнос-Айрес',
                },
                {
                    value: 'cordoba',
                    label: 'Кордова',
                },
                {
                    value: 'bogota',
                    label: 'Богота',
                },
                {
                    value: 'medellin',
                    label: 'Медельин',
                },
            ];

            const [value, setValue] = useState([]);
            const [checked, setChecked] = useState(false);
            const [indeterminate, setIndeterminate] = useState(false);

            const handleClick = () => {
                if (checked && !indeterminate) {
                    setValue([]);
                } else {
                    setValue(flatItems.map((item) => item.value));
                }
            };

            useEffect(() => {
                if (value.length === 0) {
                    setChecked(false);
                    setIndeterminate(false);
                } else if (value.length === flatItems.length) {
                    setChecked(true);
                    setIndeterminate(false);
                } else {
                    setChecked(true);
                    setIndeterminate(true);
                }
            }, [value]);

            return (
                <div style={{ display: "block", width: "300px", height: "300px" }}>
                    <Combobox
                        value={value}
                        onChange={setValue}
                        label="Label"
                        placeholder="Placeholder"
                        items={flatItems}
                        multiple
                        selectAllOptions={{
                            checked,
                            indeterminate,
                            onClick: handleClick,
                        }}
                        listMaxHeight="200px"
                    />
                </div>
            );
        }
        ```

        ```tsx live
        export function App() {
        ```

        `renderSelectionIcon` - свойство для кастомной настройки иконки выбора элемента. Принимает коллбэк с одним параметром: `selected`.

        ```tsx live
        import React, { useState } from 'react';
        import { Combobox } from '@salutejs/sdds-dfa';

        export function App() {
            const [value, setValue] = useState('brazil');

            const items = [
                {
                    value: 'north_america',
                    label: 'Северная Америка',
                },
                {
                    value: 'south_america',
                    label: 'Южная Америка',
                    items: [
                        {
                            value: 'brazil',
                            label: 'Бразилия',
                        },
                        {
                            value: 'argentina',
                            label: 'Аргентина',
                        },
                    ],
                },
            ];

            const renderSelectionIcon = (selected: boolean | 'indeterminate') => {
                if (selected === true) {
                    return <div style={{ width: '10px', height: '10px', borderRadius: '100%', background: 'red' }} />;
                }

                if (selected === 'indeterminate') {
                    return <div style={{ width: '10px', height: '10px', background: 'blue' }} />;
                }

                return null;
            };

            return (
                <div style={{ height: '300px' }}>
                   <div style={{ width: '400px' }}>
                        <Combobox
                            items={items}
                            value={value}
                            onChange={setValue}
                            renderSelectionIcon={renderSelectionIcon}
        ```

    <TabItem value="sortItems" label="Сортировка">
        Свойство `sortItems` принимает компаратор `(a, b) => number`.
        Сортируются только элементы первого уровня: порядок вложенных элементов и исходный массив `items` не изменяются.
        Без `sortItems` элементы отображаются в исходном порядке.

        В примере выбранные элементы перемещаются наверх при каждом изменении выбора.

        ```tsx live
        import React from 'react';
        import { Combobox } from '@salutejs/sdds-dfa';

        export function App() {
            const [value, setValue] = React.useState(['banana']);
            const items = [
                { value: 'apple', label: 'Яблоко' },
                { value: 'banana', label: 'Банан' },
                { value: 'orange', label: 'Апельсин' },
                { value: 'pear', label: 'Груша' },
            ];

            return (
                <div style={{ display: 'flex', flexDirection: 'column', maxWidth: '350px', height: '300px' }}>
                    <Combobox
                        label="Фрукты"
                        items={items}
                        multiple
                        value={value}
                        onChange={setValue}
                        sortItems={(a, b) => Number(value.includes(b.value)) - Number(value.includes(a.value))}
                    />
                </div>
            );
        }
        ```

## Размер

Размер Combobox задаётся с помощью свойства `size`. Возможные значения свойства: `"xl"`, `"l"`, `"m"`, `"s"` или `"xs"`:

```tsx live
import React, { useState } from 'react';
import { Combobox } from '@salutejs/sdds-dfa';
```

## Использование renderTarget и renderItem для расширенного варианта Combobox

`renderItem` и `renderTarget` рисуют одну и ту же ячейку: в списке и в поле. Поле собирается из `TextField`, поэтому `Combobox` сохраняет своё поведение: ввод фильтрует список, работает клавиатурная навигация. Текст поля приходит в `renderTarget` третьим аргументом — `textProps` с `textValue` и `onTextValueChange`; в Combobox это поисковый запрос.

```tsx live
import React, { useState } from 'react';
import { BodyXS, Cell, Combobox, EmbedIconButton, TextField, textFieldTokens } from '@salutejs/sdds-dfa';
import { IconPlasma, IconClose, IconDisclosureDown } from '@salutejs/plasma-icons';
import styled from 'styled-components';

const items = [
    {
        value: 'north_america',
        label: 'Северная Америка',
        subtitle: ['23 государства', '24,25 млн км²'],
        population: '580 млн',
    },
    {
        value: 'south_america',
        label: 'Южная Америка',
        subtitle: ['12 государств', '17,84 млн км²'],
        population: '430 млн',
        items: [
            {
                value: 'brazil',
                label: 'Бразилия',
                subtitle: ['27 штатов', '8,51 млн км²'],
                population: '203 млн',
            },
            {
                value: 'argentina',
                label: 'Аргентина',
                subtitle: ['24 провинции', '2,78 млн км²'],
                population: '46 млн',
            },
        ],
    },
];

const SubTitle = ({ items: subtitleItems }) => (
    <BodyXS style={{ display: 'flex', alignItems: 'center', gap: '8px' }}>
        <span>{subtitleItems.join(' • ')}</span>
        <IconPlasma size="xs" color="inherit" />
    </BodyXS>
);

const ContentRight = ({ population }) => (
    <Cell view="default" title={population} subtitle={<BodyXS>Население</BodyXS>} />
);

/* Одна и та же ячейка рисуется и в списке, и в поле. В поле население показывается отдельно, справа. */
const Region = ({ item, withPopulation = true }) => (
    <Cell
        view="default"
        title={item.label}
        subtitle={<SubTitle items={item.subtitle} />}
        contentRight={withPopulation && item.population && <ContentRight population={item.population} />}
    />
);

const TargetField = styled(TextField)`
    ${textFieldTokens.height}: 62px;
`;

const Arrow = styled(IconDisclosureDown)`
    transform: ${({ $opened }) => ($opened ? 'rotate(-180deg)' : 'none')};
`;

export function App() {
    const [value, setValue] = useState('');

    return (
        <div style={{ display: 'flex', flexDirection: 'column', maxWidth: '400px', height: '300px' }}>
            <Combobox
                items={items}
                value={value}
                onChange={setValue}
                renderItem={(item) => <Region item={item} />}
                renderTarget={(item, opened, textProps) => (
                    <TargetField
                        label="Title"
                        placeholder={item ? undefined : 'Placeholder'}
                        value={textProps?.textValue ?? ''}
                        onChange={(event) => textProps?.onTextValueChange(event.target.value)}
                        contentLeft={
                            item && !opened && !textProps?.textValue ? (
                                <Region item={item} withPopulation={false} />
                            ) : undefined
                        }
                        contentRight={
                            item && !opened && !textProps?.textValue ? (
                                <div style={{ display: 'flex', alignItems: 'center', gap: '8px' }}>
                                    <ContentRight population={item.population} />
                                    <EmbedIconButton
                                        size="m"
                                        view="default"
                                        aria-label="Очистить"
                                        onMouseDown={(event) => event.preventDefault()}
                                        onClick={(event) => {
                                            event.stopPropagation();
                                            setValue('');
                                        }}
                                    >
                                        <IconClose size="s" color="inherit" />
                                    </EmbedIconButton>
                                </div>
                            ) : (
                                <Arrow $opened={opened} size="s" color="inherit" />
                            )
                        }
                    />
                )}
            />
        </div>
    );
}
```

### Контракт renderTarget

`renderTarget?: (value, opened?, textProps?) => ReactNode`

- `value` — выбранный элемент, в режиме `multiple` — массив выбранных; `null`, если ничего не выбрано;
- `opened` — признак открытого списка;
- `textProps` — `{ textValue, onTextValueChange }`, текст поля. В Combobox `textValue` содержит только поисковый запрос: стартует пустым и сбрасывается при выборе, закрытии списка, `Tab` и `Escape`; фильтрация и клавиатурная навигация работают поверх него.

Что ядро делает само при кастомном target:

- открывает и закрывает список по клику — `onClick` прокидывается в обёртку target;
- обеспечивает клавиатурную навигацию — `onKeyDown` прокидывается в обёртку target;
— фильтрует список по `textValue` и управляет его жизненным циклом.

На стороне пользователя остаются разметка поля, привязка текста поля (`value={textProps?.textValue}`, `onChange` → `onTextValueChange`) и логика очистки значения.
